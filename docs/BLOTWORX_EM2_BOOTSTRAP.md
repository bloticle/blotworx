## PC persistent texture compatibility

The PC house diffuse and normal textures use `NiPersistentSrcTextureRendererData`, target 8, tiling 0, canonical little-endian BC blocks. Previously the shared image loader sent every non-Wii persistent texture through the Wii U GX2 deswizzler. That platform dispatch was inappropriate for PC data; however, the native before/after capture showed that changing it alone did not remove the visible corruption. The shared loader now routes these verified PC resources to bounded native BC1/BC2/BC3 decoding, validates every mip span, and refuses unsupported PC formats instead of applying console tiling. Source layout cross-check: Gamebryo NiDX9PersistentSrcTextureRendererData::LoadBinary and Wii U decompilation NiPersistentSrcTextureRendererData::LoadBinary (339042).

Original PC wood diffuse and normal resources both decode at 512x256. Four focused tests pass (PC persistent BC layout/truncation, existing standard BC layout/truncation, PC archive reads, Wii archive reads). The original EM1 texture fixture remains to be run through the rebuilt engine; the lightweight probe does not claim original-data regression coverage.
